# Portafolio web

Sitio estático preparado para publicarse mediante GitHub Pages.

## Publicar

1. Descomprime el ZIP en tu computadora.
2. Crea un repositorio público nuevo en GitHub (por ejemplo, `portafolio`).
3. En **Add file > Upload files**, arrastra el contenido de la carpeta extraída (no el ZIP). Asegúrate de que `index.html` quede en la raíz junto a `assets/`, `videos/` e `icons/`.
4. Confirma con **Commit changes**.
5. En **Settings > Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/(root)`, y guarda.
6. Abre el enlace que aparezca en Pages.

El sitio utiliza bibliotecas externas que requieren conexión a Internet.
